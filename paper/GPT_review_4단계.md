# GPT 검증 요청 — 4단계 (모델 벤치마크)

**요청 목적:** 모델링 설계·성능 해석의 타당성 검토 및 SHAP 대상 모델 선정 판단 확인.

## 1. 설계 요약
- 데이터: N=155,522, 타깃 발생률 26.6%(중간 불균형).
- 분할: 층화 무작위 80/20 (train 124,417 / test 31,105), seed=42.
- CV: 학습 세트 5-fold 층화.
- 불균형 보정: 트리 `scale_pos_weight`=2.757, 선형/RF class weight balancing.
- 지표: 주 ROC-AUC·PR-AUC, 보조 F1·정밀도·재현율·Brier.

## 2. 성능 결과

| 모델 | CV ROC-AUC | Test ROC-AUC | Test PR-AUC | F1 | Brier |
|---|---|---|---|---|---|
| RandomForest | 0.7035±0.0010 | **0.7104** | 0.4621 | 0.4706 | 0.1984 |
| LightGBM | 0.7007±0.0017 | 0.7066 | 0.4595 | 0.4954 | 0.2133 |
| XGBoost | 0.6997±0.0024 | 0.7045 | 0.4554 | 0.4939 | 0.2155 |
| LogisticRegression | 0.6058±0.0025 | 0.6020 | 0.3400 | 0.4165 | 0.2418 |

## 3. 판단 사항 (검토 요청)
1. **SHAP 대상 모델:** RandomForest가 근소 우위(ΔAUC<0.006, 트리 3종 동률)이나, 사전 선언 방법론(README: "XGBoost+SHAP")과 문헌 표준에 따라 XGBoost를 해석 대상으로 선정함. → 이 선택이 리뷰어에게 방어 가능한가? 아니면 최고 성능(RF)으로 통일해야 하는가?
2. **성능 수준:** Test AUC ~0.71이 ESWA 게재 기준에서 충분한 판별력인가? 예측이 어려운 사회과학적 타깃임을 감안한 서술 전략은?
3. **캘리브레이션:** Brier 0.20 수준 — 확률 캘리브레이션(Platt/Isotonic) 추가 필요성?
4. **하이퍼파라미터:** 고정값 사용(튜닝 미실시). 베이지안/그리드 탐색 추가가 필요한가, 아니면 CV 안정성(표준편차 <0.003)으로 충분한가?
5. **추가 벤치마크:** 단순 규칙 기반/다수예측 baseline, 또는 캘리브레이션된 확률 임계값 최적화 필요 여부.
